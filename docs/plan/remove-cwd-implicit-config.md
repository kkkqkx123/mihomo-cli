# 移除隐式当前目录配置

目标目录的偶发 `config.toml` 不再影响命令结果，所有特殊配置路径必须显式指定或来自用户目录。

## 范围

* TOML 解析不再查看当前目录，仅接受显式路径与用户目录文件。
* Mihomo 配置查找不再查看当前目录，顺序为显式路径高于 TOML 中配置的文件高于用户标准路径。
* 内核可执行文件搜索不再包含当前目录，显式相对路径以 TOML 所在目录为基准，无基准时直接报错。
* 服务安装时的可执行文件搜索同样不再包含当前目录。

## 显式参数

* 全局保留 `--config` 用于 CLI 连接配置。
* 新增全局 `--toml` 用于 TOML 配置，启动、停止、状态、重载、编辑与备份命令统一使用该值。
* Mihomo 配置继续使用各子命令已有的 `--path` 与 `--mihomo-config` 参数，缺省时走用户标准路径。
* 显式路径不存在直接报错，不回退其他位置；缺省且用户目录无文件时报错并提示所需参数。

## 行为变化

* 过去在目标目录放一个 `config.toml` 即被自动拾取，现在会被忽略，必须用 `--toml` 指向它。
* 缺失 TOML 不再返回默认配置，调用方必须处理缺失错误。
* 相对可执行路径无 TOML 目录上下文时不再按当前目录解析，直接报错。
* 停止命令移除与全局冲突的本地路径标志，统一走全局参数加显式实例选择。

## 验收

* 任意空目录执行启动与状态命令均指向同一用户目录文件，不受目录内容影响。
* 显式指定不存在路径时报错且不继续搜索。
* 备份与编辑在无显式路径时仅使用用户标准路径或 TOML 指向文件。
* 可执行文件搜索结果与当前目录无关。
